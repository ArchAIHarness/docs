# 模型发展趋势预判——从格局到趋势的纵深分析

> 本文是《国内AI大模型格局——从Chatbot到Agent时代切换》的续篇。前文侧重格局判断，本文侧重趋势预判。所有观点基于 2026 年 6 月公开信息和实际使用体感，判断维度不是跑分，是产品体验和竞争格局。

---

## 一、模型开始有"个性"——从跑分竞赛到能力分化

2024-2025 年的模型竞争核心是"谁的跑分更高"，各家模型像是同一个目标的参赛者，差异只在分数高低。到了 2026 年，这个局面已经变了——模型不再是同质化的跑分工具，而是开始呈现出各自鲜明的"个性"和生态位。

这不是一个主观感受，而是有数据支撑的结构性分化：

| 模型 | 核心能力标签 | 证据（2026年6月） |
|------|------------|----------------|
| **DeepSeek V4** | 编码推理最强 + 极致性价比 | SWE-bench Pro 领先，V4-Flash 输出 $0.28/MTok，成本仅为同级模型的 1/5~1/10 |
| **GLM-5.2** | 长周期自主编程 + 开源旗舰 | FrontierSWE #3（仅差 Opus 4.8 约 1%），MIT 协议，1M 无损上下文 |
| **豆包 Seed 2.0 Pro** | 多模态/视频理解最强 + 大众场景 | VideoMME 89.5（国内 VLM 第一），155M WAU 验证规模化能力 |
| **Kimi K2.6** | Agent Swarm 编排独特优势 | 原生支持 300 子代理并行、4000 步协调动作 |
| **MiniMax M3** | 开源 + 多模态 + 1M 上下文的唯一交集 | 首个同时做到三者，且支持桌面操作 |
| **Qwen 3.7 Max** | 最长自主运行 | 35 小时连续执行、1000+ 顺序工具调用 |

各家在 benchmark 上可能互有胜负，但在实际使用中，选模型已经不是"挑一个最好的"，而是"按场景挑最合适的"——这本身就是具备商业化价值的信号。

**判断**：模型同质化竞争阶段已经过去，能力分化意味着模型层正在走向成熟，这是商业化落地的前提条件。

## 二、国内外差距：benchmark 接近，但 Agent 长程任务仍有半代差距

这是争议最大的话题。一方面基准测试的数据很好看，另一方面实际体感又有明显差异。需要分开说。

### 基准测试层面：差距已经极其接近

Stanford HAI 2026 AI Index 给出的判断是：中美模型能力差距已缩小到 0.3%~1.7%。具体来看：

- GLM-5.2 在 SWE-bench Pro 上 **超过 GPT-5.5**（62.1 vs 58.6）
- 在 MCP-Atlas（Agent 工具编排）上 **追平 Opus 4.8**（77.0 vs 77.8，差距不到 1 分）
- GLM-5.2 在 Code Arena 前端盲测中排名第一，超过所有闭源模型

如果只看 benchmark，甚至可以说国内头部模型已经进入全球第一梯队的中上游。

### 但在 Agent 长周期任务上，差距仍然明显

基准测试大多是单轮或短周期任务，而 Agent 场景是"长时间自主执行"。在这个维度上，差距没有被抹平：

| 长周期 Agent 基准 | GLM-5.2 | Opus 4.8 | 差距 |
|---|---|---|---|
| **NL2Repo**（自然语言 → 完整仓库） | 48.9 | 69.7 | 差 20 分 |
| **SWE-Marathon**（马拉松式编程） | 13.0 | 26.0 | 差一倍 |
| SWE-bench Pro | 62.1 | 69.2 | 差 7 分 |
| SWE-bench Verified | ~62% | 88.6% | 差 26 分 |

任务越复杂、时间跨度越长，差距越明显。这正是"体感"比"跑分"更真实的体现——单轮问答看不出差别，但让 Agent 独立跑几十分钟甚至几小时的任务时，Opus 4.8 的稳定性和可靠性明显更高。

**判断**：在短周期 benchmark 上差距已接近抹平，但在长周期 Agent 任务上，国内头部模型与 Opus 4.8 / GPT-5.5 仍有约半代到一代的差距。Benchmark 可以优化，但 Agent 场景的泛化性和可靠性才是真实水平。

## 三、VLM 已成标配——各家都已跟上

VLM（视觉语言模型，文本+图像/视频理解）在 2026 年已经不是少数玩家的专利，而是各家实验室的基本能力。

- **智谱**：GLM-4.5V 已有 VLM 能力，GLM-5.x 虽是文本旗舰但 VLM 线并行迭代
- **DeepSeek**：DeepSeek-VL 系列持续更新，V4 虽是文本旗舰但 VLM 分支在跟进
- **豆包**：Seed 2.0 Pro 原生多模态，VideoMME 89.5 国内第一，超 Gemini 3.1 Pro
- **MiniMax**：M3 原生支持 text+image+video，且开源，是目前唯一做到"开源+多模态+1M 上下文"三者合一的模型
- **Qwen**：3.7 Plus 有多模态能力
- **百度**：ERNIE 5.1 也有多模态能力

VLM 梯队大致如下：

- **第一梯队（综合最强）**：GPT-5.5、Opus 4.8
- **国内上游**：豆包 Seed 2.0 Pro（VLM 实测国内第一）、GLM（VLM 线）、DeepSeek（VLM 线）、百度 ERNIE 5.1
- **有 VLM 但稍弱**：MiniMax M3、Qwen 3.7 Plus

**判断**：VLM 已成为模型标配能力。下一个战场不是"谁有 VLM"，而是"谁的 VLM 能在真实场景中更低成本、更稳定地运行端到端任务"。

真正的趋势在于：VLM 正在从"看图说话"走向"视觉驱动的自主执行"——

- **短期（6-12 个月）**：VLM 的竞争焦点是视频理解深度和长视频流处理能力。豆包 Seed 2.0 Pro 的 VideoMME 89.5 已经证明国内有能力做到全球上游，但真正的挑战是把视频理解从秒级片段扩展到分钟级的连续理解。
- **中期（1-3 年）**：视觉能力将与 Agent 框架深度整合——Agent 不再是"读文字指令执行"，而是"看屏幕/看摄像头/看图直接行动"。Desktop Agent、GUI Agent 的爆发需要 VLM 在延迟和成本两个维度同时达到可用门槛。
- **长期信号**：MiniMax M3 是目前唯一做到"开源+多模态+1M 上下文+桌面操作"四合一的产品——"桌面操作"这一步是关键信号：VLM 正在从感知层进入执行层。

国内头部已经和全球第一梯队在同一张桌子上吃饭了。下一个问题是：谁能把 VLM 从"模型能力"转化为"可规模化的产品能力"。

## 四、企业级 Agent 产品正在重新定义模型需求

模型发展的下一步驱动力不完全来自实验室，也来自产品端提出的新需求。2026 年浮现的几个企业级 Agent 产品，直接影响了模型层的能力优先级。

### 腾讯 WorkBuddy：多模型编排从概念变成产品

2026 年 6 月，腾讯云发布 WorkBuddy——定位"全场景 AI Agent 桌面工作站"。这不是一个聊天助手：用户给一句话，Agent 自主规划、分解、执行，直接交付报告、PPT、数据分析或网页应用。

关键信号不是产品本身，而是它对模型层的影响：

1. **多模型并行调用**：WorkBuddy 通过 TokenHub 统一管理 DeepSeek、GLM 等多模型调用，实际场景中一次任务可能同时调用不同模型——编码用 DeepSeek、长文理解用 Kimi、视觉用豆包。这对模型的**互操作性**和**API 标准化**提出了新要求。
2. **场景定义模型选型**：WorkBuddy 实践中发现，不同场景需要的模型"个性"完全不同——编程场景要推理强、分析的场景要上下文长、文档生成要输出质量高。这正是第 1 节"模型开始有'个性'"的直接产品侧验证。
3. **混元弱不影响产品**：虽然自研模型混元起步晚、能力弱，但 WorkBuddy 通过 TokenHub 屏蔽了模型差异。"模型是插件，场景是主体"——这是字节模型网关策略在企业级 Agent 产品端的镜像。

**趋势信号**：企业级 Agent 产品正在把模型需求从"谁最强"变成"谁最适合特定任务、谁最容易集成"。这对模型厂商意味着：API 质量和生态整合能力正在成为比 benchmark 排名更重要的竞争优势。

### 通义的人才震荡与组织结构的代价

2026 年上半年，通义千问团队经历了核心人才流失的罕见密集期：

- **2026 年 1 月**：Qwen Code 负责人惠彬原离职加盟 Meta
- **2026 年 3 月**：Qwen 技术负责人林俊旸离职，后训练负责人郁博文、核心贡献者李凯新同日离职。林俊旸留言 "me stepping down. bye my beloved qwen."
- **2026 年 6 月**：阿里首席科学家周靖人被曝离职（仅履新 6 天），通义核心模型团队被划入 CEO 吴泳铭直管的 Token Foundry

根本原因是组织架构调整与开源/商业化路线分歧的集中爆发——林俊旸主张"预训练-后训练-Infra"全链路垂直整合，而集团要求拆分为水平分工团队。这不是个别人才的离开，是**组织结构性矛盾对模型研发的直接影响**。

Qwen 3.7 Max 在 SWE-bench Pro 上仍跑出 60.6%（国内最高），说明技术底子没丢，Google DeepMind 的周浩加入负责后训练也是正向补充。但半年内 4 位核心人物离开，对迭代节奏的损伤是可见的——从第 1 节的迭代 timeline 可以看出，Qwen 3.5 到 3.7 每代都被对手压制，节奏乱了的根本原因就在这里。

**趋势信号**：模型研发不再是纯粹的技术竞赛，**组织结构和人才管理正在成为模型竞争力的决定因素**。在模型迭代速度决定市场位置的周期里，团队稳定性直接影响节奏，节奏影响市场份额，份额反过来影响资源投入——这是一个正向/负向循环。

## 五、算力的真相：结构性错配，长期趋势是供大于求

### 算力市场不是一个统一市场

当前算力市场的矛盾在于：供应商喊缺货，用户觉得贵，但实际利用率并不高。拆开看才发现是分层市场的结构性错配。

**供大于求的信号（成熟算力层）：**

- H100 云租赁从 2023 年初 $8/hr → 2026 年 Q2 **$1.80-3.50/hr**，降幅超 50%
- B200 租金在 2026 年 6 月 3 周内跌了 **30%**（$6.11→$4.22）
- H100 交货周期从 50+ 周降到了 **6-12 周**
- 企业端 GPU 实际利用率中位数仅 **40-70%**，大量 GPU 买了但没充分跑起来
- VentureBeat 调查显示企业 GPU 平均利用率仅 5%（统计口径偏保守，但方向确定）

**供不应求的信号（高端算力层）：**

- Oracle CEO 声称全球 GPU 利用率 97.5%
- GB200 NVL72 整机柜仍在 tight allocation
- 高端集群（H200/B200/大规模集群）仍需要配额和关系

**本质是结构性错配**：成熟算力已经过剩、价格下行，但高端算力仍然偏紧。不是供应商在刻意制造稀缺，而是算力品类、地域、规模之间的供需不匹配。

### 长期判断：供大于求是大概率事件

当前 token 消耗的主力人群仍然是程序员和技术开发者，受众面偏窄。Agent 应用还没有大规模铺开，大众场景的 token 消耗还没真正起量。

但供应侧的增长是确定的——TSMC 产能持续释放，国产算力（华为昇腾、寒武纪）逐步放量，云厂商的算力基础设施投资还在加速。一旦 Agent 应用爆发带来的需求增长跟不上算力供给的增长，供大于求的局面就会更加明显。

### Token 定价趋势

Token 定价正在走宽带的老路——从高价按量计费，走向月租+按量混合模式。

已经发生的：
- 模型 API 价格持续下降，GLM-5.2 输出 $4.40/MTok，Opus 4.8 输出 $25/MTok，价差约 5.7 倍
- DeepSeek V4-Flash 输出仅 $0.28/MTok——已接近"token 当流量卖"的逻辑
- AI Gateway / TokenHub 等统一计费层出现，按量计费、预付费套餐模式正在成型

**个人预判**：Token 价格下降不可逆。但和宽带不同的是，这次定价权掌握在资本市场手中，而非国家管控——这增加了市场波动的不可控性。Token 只是载体，数据才是生产资料，谁能掌握定价权，谁就在下一阶段拥有主动权。

## 六、模型网关——未来数据长城的 3 座关隘

### 模型网关不是"中转分发"这么简单

"3 座关隘"的类比——模型网关 + API 网关 + 租户数据网关——精准概括了 AI 基础设施的关键分层。模型网关在 2026 年已经不是一个可选项，而是正在成为核心基础设施层。

几个事实支撑：

1. **市场验证**：全球模型路由市场 2026 年已达 **$3.04B**，CAGR 20.8%。OpenRouter、TokenHub（腾讯）、GateRouter、LiteLLM 等已成标准组件。
2. **技术演进**：从 2024 年的单一路由分类器（RouteLLM），到 2026 年的**复合路由架构**（Mixture-of-Routers），支持级联（先便宜后贵）、竞速（谁快用谁）、语义缓存、多目标优化等策略——这不是"中转分发"，这是**智能流量调度层**。
3. **行业共识**：IBM、AWS 等已将 AI Gateway 定位为"AI 时代的 API 网关"，类比传统 IT 架构中的负载均衡和 CDN。

### 模型网关的 2 类形态

模型网关的发展方向大致分两类：**一类是模型自带路由能力，按任务自主切换；另一类是独立网关 + 模型，按需调度**。二者不是非此即敌的关系，而是面向不同场景的互补路径。

2026 年的前沿研究正在验证这两个方向：

- **自路由模型**：Self-Routing（ACL 2026）已证明可以用隐藏状态内置路由能力，无需独立路由器参数。EvoRoute（ACL 2026）实现基于经验的自演化路由决策。
- **网关 + 模型**：这是当前主流的商业化路径，字节模型网关、腾讯 TokenHub、OpenRouter 都是这个模式。

**判断**：两个方向会长期并存。自路由适合端侧和实时性要求高的场景，网关+模型适合企业级、多租户、合规要求复杂的场景。模型网关的重要性只会增长，不会降低。

## 七、模型未来三个方向

### 方向一：模型自带网关能力，按任务自主切换能力

这不是概念推演——2026 年的前沿论文已经跑通了技术路径：

- **Self-Routing**（ACL 2026）：MoE 模型的隐藏状态子空间直接用作路由信号，消除独立路由器参数
- **EvoRoute**（ACL 2026）：基于经验知识库的自演化路由，动态选择帕累托最优模型组合，成本降低 80%
- **Router-R1**（NeurIPS 2025）：路由器本身是一个具备推理能力的 LLM，能做明确的推理式路由决策

### 方向二：模型直接平替基础 Agent，解决上下文压缩和记忆问题

当前 Agent 架构中，上下文管理和记忆是最棘手的工程问题。模型自身正在吸收这些能力：

- **DeepSeek V4** 的 Compressed Sparse Attention 在 1M 上下文下将 KV 缓存压缩了 90%
- **Kimi K2.6** 原生支持 300 子代理编排，Agent Swarm 能力直接内置于模型层
- **MiniMax M3** 的 MSA（MiniMax Sparse Attention）在 1M 上下文下实现 9.7x 更快的 prefill 和 15.6x 更快的 decode

推论：未来模型和 Agent 的边界会模糊。模型不再只是"被 Agent 调用的脑子"，而是自身具备部分 Agent 能力。

### 方向三：文本+视觉一体输入输出的闭环能力

- **豆包 Seed 2.0 Pro** 已实现原生多模态（VideoMME 89.5），且是当前国内 VLM 第一
- **Opus 4.8** 支持 3.75MP 图像输入，文本+视觉已在同一模型内闭环
- **MiniMax M3** 是首个做到"开源 + 多模态 + 1M 上下文 + 桌面操作"四合一的模型

这不是多模态的终局——这只是第一步。真正的闭环是"模型能够自主调用视觉能力完成端到端任务"，而非简单的"看图说话"。当前各家都在向这个方向走，差距正在缩小，但还没有谁能说已经做到了。

## 总结：模型层正在经历的 5 个确定性变化

把全文 7 个趋势串联起来，有 5 个确定性较高的判断：

**1. 模型的能力分化是不可逆的。** 2024-2025 年的"跑分竞赛"已经结束，2026 年各家模型在编码、Agent、多模态、长上下文等方向各有所长。这对下游开发者是利好——不再只有一个选择，而是可以按场景选最优组合。

**2. 国内外差距的真实维度是"长周期 Agent 可靠性"，不是 benchmark。** 短周期基准测试上差距已接近抹平（0.3%-1.7%），但 SWE-Marathon、NL2Repo 等长周期 Agent 评测上仍有半代到一代差距。Benchmark 可以优化，Agent 场景的泛化性和可靠性才是真实水位。

**3. VLM 正在从"模型能力"走向"产品能力"。** 各家 VLM 在 benchmark 上差距不大，真正的分水岭是谁能先让 VLM 在真实场景中低成本、低延迟地跑端到端任务。Desktop Agent 和 GUI Agent 是下一个爆发点。

**4. 算力的结构性错配正在加剧，长期供大于求。** 成熟算力（H100）价格已跌去 50%+，企业端利用率仅 40-70%。高端算力（GB200 整机柜）仍然偏紧。随着国产算力放量和 TSMC 产能释放，算力供给增长速度大概率超过 Agent 应用的需求增速。

**5. 模型网关正在成为 AI 基础设施的必选项。** 全球市场规模已达 $3.04B，Self-Routing、EvoRoute 等技术路径正在把路由能力从外部网关内化到模型自身。"模型自带路由"和"网关+模型"两个方向会长期并存。

### 最关键的未知变量

同样重要的是明确承认不确定性。以下 3 个变量如果方向变了，上文的判断需要重新评估：

| 变量 | 当前假设 | 如果错了意味着什么 |
|------|---------|------------------|
| **Agent 应用的需求增速** | 尚未大规模铺开，但长期看涨 | 如果 Agent 需求 1-2 年内爆发（比预期快），算力供大于求的判断需要修正，Token 定价下行周期会提前结束 |
| **国产算力的实际可用性** | 华为昇腾、寒武纪逐步放量 | 如果国产算力在性能或产能上达不到预期，高端算力的紧张局面会持续更久，结构性错配不会自然缓解 |
| **中美模型差距的收敛速度** | 长周期 Agent 仍有半代到一代差距 | 如果国内模型的 Agent 可靠性在 1-2 代内追平（比预期快），模型选型的决策权重会从"能力"转向"生态"和"成本"——这对字节、腾讯的平台策略是重大利好 |
